# 🍕 SaLivePizza

## 📌 Overview

SaLivePizza is a simple and responsive food website designed for a pizza brand. It displays pizza items and provides a clean and user-friendly interface.

## 🚀 Features

* Responsive design
* Clean and modern UI
* Pizza menu display
* Easy navigation

## 🛠️ Technologies

* HTML
* CSS
* JavaScript

## 🎯 Purpose

This project is created for practicing frontend web development.
